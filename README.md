# 理杏仁通用金融数据查询 Skill v2.0

> 零门槛、免代码，一句话查询 A 股全品类金融数据。

---

## 🚀 零基础配置（3步搞定）

### Step 1：获取理杏仁 Token
1. 访问 [https://www.lixinger.com/open/api](https://www.lixinger.com/open/api)
2. 登录账号 → 点击右上角头像 → 进入「个人中心」
3. 找到「API 管理」或「开放平台」入口
4. 点击「创建 Token」（免费，实名认证后可创建）
5. 复制生成的 Token 密钥（格式类似 `xxxx-xxxx-xxxx-xxxx`）

### Step 2：配置 Token
对 AI 说：
```
设置理杏仁 Token：你复制的Token值
```

### Step 3：开始查询
```
查询贵州茅台最近5年的PE估值分位
查询迈瑞医疗2020-2024年的营收和净利润
查询宁德时代近5年的分红情况
```

## ❗ 常见问题

**Q：查询返回空数据？**
A：① 检查时间范围 ② 确认是否为金融股（银行/证券/保险需用专用接口）③ 央企高管增减持通常不公开，返回空为正常

**Q：提示 Token 鉴权失败？**
A：Token 可能已过期，请至理杏仁官网重新生成后更新

**Q：查询频率受限？**
A：Skill 内置自动等待重试，无需手动操作；频繁报错时稍等片刻再试

**Q：毛利率/资产负债率看起来数值很小？**
A：理杏仁返回小数格式（如 0.55 表示 55%），Skill 会自动乘以 100 转为百分比展示
